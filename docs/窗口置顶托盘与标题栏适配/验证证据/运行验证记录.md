说明：关闭到托盘最初只做了 Rust `prevent_close()`，实机发现 Tauri 的 JS `onCloseRequested` 在没有调用 `event.preventDefault()` 时会执行 `destroy()`，进程仍会退出。修复为前端同时调用 `event.preventDefault()` 和 `hide()`，Rust 保留兜底。
